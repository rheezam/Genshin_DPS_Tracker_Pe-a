# Genshin_DPS_Tracker_Pe-a
Genshin DPS Tracker merupakan program yang dirancang untuk membantu pemain Genshin Impact mengelola data karakter, menyusun kombinasi tim, mengatur build, serta mencatat dan membandingkan hasil pengujian Damage per Second (DPS). Program ini bertujuan mempermudah dokumentasi eksperimen agar pemain dapat mengevaluasi performa berbagai kombinasi tim dan build karakter.

Program ini memiliki dua jenis pengguna, yaitu admin dan user. Admin bertugas mengelola akun pengguna, data karakter, preset pengujian, dan target dummy, sedangkan user dapat mengelola tim dan build karakter, mencatat hasil DPS secara manual, serta melihat riwayat pengujian. 

Melalui fitur tersebut, program ini juga menerapkan konsep algoritma dan pemrograman, seperti percabangan, perulangan, validasi input, dan pengelolaan struktur data.
